# Functional Specification: Import, Export & System Integrations

## 1. Overview
Details requirements for data exchange, CAD exports, third-party planning software integration, and project sharing.

## 2. Export Formats
- **CAD / Vector Export:** Export diagrams and cabinet layouts to DXF / DWG for CAD post-processing.
- **Print & PDF Documentation:** Generate complete project documentation handbooks including title page, table of contents, circuit schematics, cabinet layout, terminal schedules, and material BOMs (Bill of Materials).
- **QR Code Sharing:** Generate direct access QR codes linking to mobile viewports or project states.

## 3. Third-Party Integrations
- **jetplan.de Integration:** Bi-directional or import pipeline for architectural floor plan layout data.
- **Gira GPLA Tool:** Import configuration data from Gira project planning.
- **Sparkify / Measurement Protocols:** Import verification, insulation test data, and measurement values into project records for official compliance documentation.
- **Project Collaboration:** Project sharing, status tracking (In Progress, Approved, Completed), and multi-user access controls.
