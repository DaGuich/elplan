# Functional Specification: Collaboration, Workspace Management & External Integrations

## 1. User Workspace & Access Control
- **Role & Rights Management:** Account owners, employees, invited client access.
- **Client Collaboration Portal:** Restricted client view mode with symbol visibility controls, symbol restriction/customization, and public sharing via direct link or QR code.
- **Workspace & License Management:** Multi-workspace project transfer, license limit tracking, and home-screen PWA capabilities.

## 2. Export & External System Integrations
- **CAD & Vector Export:** Export schematics and cabinet layouts to DXF / DWG vector formats for CAD post-processing.
- **Third-Party Integrations:**
  - **jetplan.de Integration:** Import architectural floor plan data and symbol overlays.
  - **Gira GPLA Tool:** Import configuration data from Gira project planning.
  - **Sparkify Protocol Integration:** Import insulation test values, loop impedance readings, and verification protocols directly into project records for compliance reporting.
- **Documentation Handbooks:** Generate complete printable PDF project documentation handbooks combining cover page, table of contents, floor plans, circuit schematics, cabinet assembly diagrams, terminal schedules, and material BOMs.
